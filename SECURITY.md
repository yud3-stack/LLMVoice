# Security Policy

## Supported Versions

During Early Access, only the latest release on the `main` branch is supported
for security fixes.

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting for this repository when available. If it is not
available, contact the repository owner privately through GitHub before sharing
reproduction details.

Do not upload private voice recordings, model files, credentials, or complete
local installer logs. Remove usernames, local paths, and tokens from diagnostics.

## Scope

Relevant reports include unsafe archive or installer behavior, arbitrary command
execution, path traversal, credential exposure, updater signature failures, and
unexpected network or telemetry behavior.
